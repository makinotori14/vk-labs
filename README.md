# CG Lab03

Вариант 6 — Пирамида

Базовое задание: одна PNG-текстура альбедо, UV-координаты, динамический
uniform-буфер и общий набор дескрипторов с image-sampler. Вершины и индексы
загружаются в GPU-память через staging-буферы. Камера и освещение — из лабораторной №2.

```bash
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

Шейдеры и текстура находятся в каталоге сборки. Пути к ним задаются при сборке,
поэтому запускать приложение можно из любой рабочей папки.
